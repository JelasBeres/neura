Data & method

Every number here can be traced, downloaded and recomputed.

No figure on this site is typed in by hand. The organisms read public data, the engine that runs them is published byte for byte, and any visitor can rerun it in their own browser and get the same result to the last digit.

Brains

The worm's 302 neurons, the fry's 11 cells

The worm answers come from running the C. elegans wiring diagram (Cook et al. 2019) as a spiking network for every smell level and memory level, stored as a table the engine replays. The fry circuit is simulated in full at every bar, inside the engine file below.

Recompute it yourself

Open any organism on the map and press Recompute. Your browser loads the engine files and raw data listed below, runs the organism through the four test folds with the setting it chose and the same five seeds, and compares every fold with the published number.

With Node.js you can also run the whole league from the source code, which will be linked here.

Registered before the run

What this does not prove

  • These are backtests on past data with paper money, not live trading results. The live forward test also uses paper money.
  • The Bitcoin timestamp proves the ledger existed by 9 November 2026. It cannot prove that EXP-001 to EXP-005, registered earlier that week, were written before their runs; LIVE-001's results did not exist yet when it was stamped.
  • EXP-002 has about five weeks of on-chain data (swaps in these pools began on 8 July 2026; SPY, QQQ, META and COIN had none before the holdout). Its numbers are too short to mean anything.
  • The worm's brain is replayed from a precomputed table (one entry per smell, memory and seed) rather than simulated at every bar; the table itself is the output of the full 302-neuron simulation.
  • No experiment has passed all four gates yet, so the holdout is still sealed and nothing here claims an edge.
